ASH Turtle - Secret Logo Easter Eggs

Open student_images.py and scroll to the bottom.
Remove the # from any image_sequence.append(...) line to display a logo.
Then run student_sequence.py in Thonny.

Functions: nike_logo(), billabong_logo(), toyota_logo(), nasa_logo(), dominoes_logo().
These are simplified, educational approximations of familiar logos, not exact reproductions.
All original student drawings, sounds and backgrounds have been retained.
