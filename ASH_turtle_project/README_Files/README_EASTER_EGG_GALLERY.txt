EASTER EGG GALLERY
==================
All five logo imports and sequence entries are in easter_egg_gallery.py.

To enable the gallery, open student_images.py and remove the # from BOTH lines:

from easter_egg_gallery import easter_egg_sequence
image_sequence.extend(easter_egg_sequence)

To choose which logos appear, comment out entries inside easter_egg_gallery.py.
Keep easter_eggs.py in the same project folder.
