STUDENT IMAGE STYLES + VERY FAST DEFAULT

Run student_sequence.py in Thonny on Windows.

In student_images.py, put ("color", "red") and ("width", 5) at the beginning of any image instructions.
Each image starts with default black colour and width 3; students can override these per item.
Fill colours are separate: ("fillcolor", "yellow").

In teacher_sequence.py, global default drawing speed is 45 pixels/frame and the frame interval is 5ms.
Speed +/- buttons change movement by 5 pixels/frame, between 1 and 100.

Music remains independent, with per-chord tempo in student_sounds.py.
Audio requires Windows winsound.
